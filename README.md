# आस्था (Aastha for Women) 🌸

> **Official Web Platform for Aastha for Women (NGO)**  
> Empowering women and adolescent girls through compassionate counselling, marital mediation, vocational livelihoods, and 24x7 crisis intervention across Maharashtra.

---

## 🌟 Key Features

- **Multilingual Support (3 Languages):**
  - English (`EN`)
  - हिन्दी (`HI`)
  - मराठी (`MR`)
- **Three-Step Community Journey ("How We Help"):**
  - Pre-Marital & Adolescent Girl Guidance
  - Crisis Mediation & Mental Health Circles
  - Vocational Tailoring & Livelihood Training
- **Founder’s Story & Philosophy:**
  - Dedicated journey of Simintini Shingade
  - Interactive "Full Founder Journey" modal with verified testimonials & grassroots background
- **Living Fieldwork Gallery ("Where Change Takes Root"):**
  - 17 authentic grassroots photographs
  - Smooth Wide-Lens Rotating Carousel with auto-rotate and pause-on-hover
  - Full Documentary Grid View ("All Photos")
  - High-resolution modal lightbox with complete narrative details
- **Strategic Horizon Roadmap 2026–2027 ("The Future We’re Building"):**
  - Phased horizon cards with real verified ground deliverables
  - Official posters and field photographs for campus guidance, cloud kitchens, and 24x7 helpline
- **Confidential Guidance & 24x7 Helpline:**
  - One-click "Request Guidance" modal
  - Quick Exit button for sensitive browsing protection
  - Direct toll-free and state coordination contacts

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS + PostCSS
- **Icons:** Lucide React
- **Typography:** Playfair Display (Serif) + Inter (Sans)
- **Deployment:** Static Build / Vercel / Netlify / Cloudflare Pages

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / yarn / pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/agrawalpratibha63/astha-for-women.git

# Navigate to project directory
cd astha-for-women

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
# Compile and optimize for production
npm run build

# Preview production build locally
npm run preview
```
